# sc-portfolio-docs

Shared documentation for the Day One Citizen fan-site network (dayonecitizen.com and its
satellites). It lives inside the `sc-portfolio` workspace as `docs/`.

| Folder | What it holds |
|---|---|
| `claims/` | Claims ledger: one file per fact, with canonical text, status, official sources, `lastVerified` and usage |
| `seo/` | SEO strategy, keyword research, audits, migration reports |
| `audits/` | Site and content audits |
| `sc-ask/` | Verify the Verse (SC Ask) notes |
| `superpowers/` | Design specs and implementation plans |
| `video/`, `reddit/`, `prompts/` | Video pipeline notes, community drafts, reusable prompts |

Rules: official Cloud Imperium sources only; no game-file citations; never commit keys or
tokens (this repo is **public**, and push protection is on).
