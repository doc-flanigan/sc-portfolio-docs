# SC Ask Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A password-gated web chat at `ask.dayonecitizen.com` that answers Star Citizen questions with a verdict, grounded only in our mirrored official-CIG corpus + claims ledger, every statement cited.

**Architecture:** An ingest pipeline in `sc-portfolio/tools/commlink-corpus/ask/` chunks comm-links, dev posts, YouTube transcripts and ledger claims into an Upstash Vector hybrid index (hosted `bge-m3` dense + BM25 sparse). A new Next.js 15 app (`sc-ask` repo, Vercel) retrieves passages, calls Claude Haiku 4.5 once per uncached question, streams NDJSON events to a chat UI, and keeps cache/stats/spend in Upstash Redis. A nightly GitHub Action syncs new sources, ingests deltas, evicts affected cache entries, and posts a summary to Discord `#ask-log`.

**Tech Stack:** Node 22, `@upstash/vector`, `@upstash/redis`, `@upstash/ratelimit`, `@anthropic-ai/sdk`, `yaml`, Next.js 15 (App Router, TypeScript, no Tailwind), Vitest, `node:test`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-28-sc-ask-design.md` (sc-portfolio-docs repo). Read it before starting any task.

## Global Constraints

- Model: `claude-haiku-4-5-20251001`; prices $1/MTok input, $5/MTok output → cost in microdollars = `input_tokens * 1 + output_tokens * 5`.
- Per request: question ≤ **500** chars; passages ≤ **24,000** chars (~6k tokens); `max_tokens` **700**.
- Retrieval: main hybrid query topK **24** → ≤ **3** passages per doc → keep **12** total; ledger via separate dense query topK **3**, included when score ≥ `LEDGER_MATCH_SCORE` (default **0.88**).
- Cache hit when dense score ≥ `CACHE_HIT_SCORE` (default **0.92**); cache record TTL **30 days**; nightly eviction when a new passage's dense score ≥ `INVALIDATE_SCORE` (default **0.86**).
- Spend cap `ASK_MONTHLY_CAP_USD` default **10**; warn at **80%**; at 100% → cache-only mode.
- Rate limit (built, **disabled** while private): **10**/hour and **40**/day per IP for uncached questions.
- Verdicts: `supported | contradicted | changed | not_found | none`. `contradicted` requires an explicit official passage; absence → `not_found`, never "false".
- Topics (fixed): `Ships, Insurance, Wipes & persistence, FPS, Base building, Economy & trading, Pledging & money, Events & Free Fly, Squadron 42, Release dates & roadmap, Other`.
- The chat **never writes to the claims ledger**. No referral link anywhere in sc-ask.
- Footer on every page: unofficial fan tool disclaimer + RSI "Made by the Community" mark.
- One question at a time — no conversational context sent to the model.
- Discord = `#ask-log` webhook only (no bot, no buttons, no public channel — tabled to v2).
- Upstash namespaces: `docs` (passages), `cache` (answered questions). Redis keys exactly as in **Shared contracts** below.
- Commit convention: `feat:`, `fix:`, `chore:`, `docs:`, `test:`; commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

### Shared contracts (both repos rely on these — do not rename)

**Passage (Upstash vector, namespace `docs`)**
- `id`: `${docId}#${n}` where `docId` ∈ `comm:<commlinkId>`, `dev:<sha1(url)[0:16]>`, `yt:<videoId>`, `ledger:<claimId>`
- `data`: passage text (Upstash embeds it)
- `metadata`: `{ docId, sourceType: 'comm'|'dev'|'yt'|'ledger', title, date: 'YYYY-MM-DD', url, author, status, ingestedAtMs: number, excerpt }`

**Cache vector (namespace `cache`)**: `id` = `qid`, `data` = canonical question, `metadata` = `{ qid }`.

**Redis keys**
| Key | Type | Written by | Meaning |
|---|---|---|---|
| `ingest:manifest` | hash docId → `${hash}:${passageCount}` | ingest | what's indexed |
| `corpus:currentTo` | string `YYYY-MM-DD` | ingest | newest non-ledger source date |
| `cache:{qid}` | JSON `CacheRecord`, EX 30d | app | cached answer |
| `q:{qid}` | hash `{question, topic}` | app | label for Most asked |
| `asked:{YYYY-MM-DD}` | hash qid → count, EX 400d | app | daily asks (UTC) |
| `asked:all` | hash qid → count | app | all-time asks |
| `hits:{day}` / `misses:{day}` | int, EX 400d | app | cache hit rate |
| `spend:{YYYY-MM}` | int microdollars | app | month spend |
| `spend:day:{YYYY-MM-DD}` | int microdollars, EX 40d | app | daily spend |
| `spend:warned:{YYYY-MM}` | "1" (SET NX) | app | 80% warning sent |
| `fb:{qid}` | hash up/down counts | app | feedback |

**qid** = first 16 hex chars of sha1(normalized canonical question), normalized = lowercase, non-alphanumerics → space, collapse spaces, trim.

## Review Focus

1. **Auto-captions with little punctuation** (a 5,000-word run-on "sentence") — chunker must still produce passages ≤ 400 words, never one giant passage. → Task 1 test `hard-splits unpunctuated text`.
2. **Model skips or garbles the VERDICT/TOPIC header** — the answer must still display (verdict `none`) and must **not** be cached. → Task 6 test `falls back when no separator`, Task 8 test `does not cache unparsed header`.
3. **Citation split across stream chunks (`"[1"` then `"2]"`) or out-of-range `[99]`** — must render `[12]` intact and strip `[99]`. → Task 6 tests.
4. **Question typed by a user contains instructions ("ignore your rules…")** or scraped passage text contains instructions — treated as data. → system prompt rule (Task 5) + eval cases `inj-1`, `inj-2` (Task 12).
5. **Ledger claim edited or deleted** after indexing — changed claims re-indexed, deleted claims removed from the index. → Task 3 tests `replace on hash change` and `stale docs are deleted`.

```js
// tools/commlink-corpus/ask/chunk.mjs
// Split long text into ~targetWords passages on paragraph/sentence boundaries,
// carrying ~overlapWords of trailing sentences into the next passage so a fact
// that straddles a boundary is still retrievable. Auto-captions can lack
// punctuation, so any over-long "sentence" is hard-split first.

export const wordCount = (s) => s.split(/\s+/).filter(Boolean).length;

export function splitSentences(text) {
  return text
    .split(/\n{2,}/)
    .flatMap((para) => para.replace(/\s+/g, ' ').trim().split(/(?<=[.!?])\s+(?=["'(\[]?[A-Z0-9])/))
    .map((s) => s.trim())
    .filter(Boolean);
}

export function chunkText(text, { targetWords = 400, overlapWords = 60 } = {}) {
  const maxUnit = Math.floor(targetWords / 2);
  const units = splitSentences(text).flatMap((s) => {
    const toks = s.split(/\s+/);
    if (toks.length <= maxUnit) return [s];
    const parts = [];
    for (let i = 0; i < toks.length; i += maxUnit) parts.push(toks.slice(i, i + maxUnit).join(' '));
    return parts;
  });

  const chunks = [];
  let cur = [];
  let curWords = 0;
  for (const u of units) {
    const w = wordCount(u);
    if (cur.length && curWords + w > targetWords) {
      chunks.push(cur.join(' '));
      const carry = [];
      let cw = 0;
      for (let i = cur.length - 1; i >= 0; i--) {
        const uw = wordCount(cur[i]);
        if (cw + uw > overlapWords) break;
        carry.unshift(cur[i]);
        cw += uw;
      }
      cur = carry;
      curWords = cw;
    }
    cur.push(u);
    curWords += w;
  }
  if (cur.length) chunks.push(cur.join(' '));
  return chunks;
}
```

```js
// tools/commlink-corpus/ask/sources.mjs
// Normalizes the four source types into Doc records for ingest.
import fs from 'node:fs';
import path from 'node:path';
import readline from 'node:readline';
import crypto from 'node:crypto';
import YAML from 'yaml';

const FILES = { comm: 'corpus.jsonl', dev: 'devtracker.jsonl', yt: 'youtube.jsonl' };
const LEDGER_STATUSES = new Set(['verified', 'refuted', 'unverifiable']);

export async function* readJsonl(file) {
  if (!fs.existsSync(file)) return;
  const rl = readline.createInterface({ input: fs.createReadStream(file, 'utf8'), crlfDelay: Infinity });
  for await (const line of rl) if (line.trim()) yield JSON.parse(line);
}

const hash16 = (s) => crypto.createHash('sha1').update(String(s)).digest('hex').slice(0, 16);
const isoDate = (v) => (v instanceof Date ? v.toISOString().slice(0, 10) : String(v ?? '').slice(0, 10));

// Dev posts often quote a non-CIG user first. The quote's end can't be found
// reliably in the flattened text, so we label it instead of stripping it; the
// system prompt tells the model not to attribute quoted words to CIG.
export function markQuotes(text) {
  return String(text)
    .replace(/>\s*\n\s*Originally posted by\s*\n\s*([^\n]+?)\s*\n/g, (_, name) => `[Quoting non-CIG user ${name.trim()}:]\n`)
    .replace(/^[ \t]*>[ \t]*$/gm, '')
    .replace(/\n{3,}/g, '\n\n')
    .trim();
}

export function toDoc(r, sourceType) {
  const text = sourceType === 'dev' ? markQuotes(r.text) : String(r.text ?? '').trim();
  if (!text) return null;
  const base = { sourceType, title: String(r.title ?? ''), date: isoDate(r.date), url: String(r.rsi_url ?? ''), author: '', status: '', text };
  if (sourceType === 'comm') return { ...base, docId: `comm:${r.id}` };
  if (sourceType === 'dev') return { ...base, docId: `dev:${hash16(r.id)}`, author: String(r.creator ?? '') };
  if (sourceType === 'yt') return { ...base, docId: `yt:${r.vid}` };
  throw new Error(`unknown sourceType ${sourceType}`);
}

export function parseLedgerFile(raw, fileName) {
  if (fileName.toLowerCase() === 'readme.md') return null;
  const m = raw.match(/^---\r?\n([\s\S]*?)\r?\n---\r?\n?([\s\S]*)$/);
  if (!m) return null;
  const fm = YAML.parse(m[1]) ?? {};
  if (!LEDGER_STATUSES.has(fm.status) || !fm.id || !fm.claim) return null;
  const date = isoDate(fm.lastVerified);
  const body = m[2].replace(/\r\n/g, '\n').trim();
  return {
    docId: `ledger:${fm.id}`,
    sourceType: 'ledger',
    title: String(fm.claim),
    date,
    url: Array.isArray(fm.sources) && fm.sources.length ? String(fm.sources[0]) : '',
    author: '',
    status: fm.status,
    text: `Claim: ${fm.claim}\nFact-check status: ${fm.status} (last verified ${date})\n\n${body}`.trim(),
  };
}

export async function* loadAllDocs({ dataDir, claimsDir, sources }) {
  for (const type of ['comm', 'dev', 'yt']) {
    if (!sources.includes(type)) continue;
    for await (const r of readJsonl(path.join(dataDir, FILES[type]))) {
      const doc = toDoc(r, type);
      if (doc) yield doc;
    }
  }
  if (sources.includes('ledger') && fs.existsSync(claimsDir)) {
    for (const f of fs.readdirSync(claimsDir).filter((f) => f.endsWith('.md')).sort()) {
      const doc = parseLedgerFile(fs.readFileSync(path.join(claimsDir, f), 'utf8'), f);
      if (doc) yield doc;
    }
  }
}
```

```js
// tools/commlink-corpus/ask/manifest.mjs
// Redis hash ingest:manifest maps docId → "<contentHash>:<passageCount>" so the
// nightly run only re-embeds new or changed docs and can delete old passages by id.
import crypto from 'node:crypto';

export const contentHash = (d) =>
  crypto.createHash('sha1').update(JSON.stringify([d.title, d.date, d.url, d.author, d.status || '', d.text])).digest('hex').slice(0, 16);

export const manifestValue = (hash, count) => `${hash}:${count}`;

export function parseManifestValue(v) {
  const [hash, count] = String(v).split(':');
  return { hash, count: Number(count) || 0 };
}

export function planDoc(hash, existing) {
  if (existing === undefined || existing === null) return { action: 'insert', oldCount: 0 };
  const prev = parseManifestValue(existing);
  return prev.hash === hash ? { action: 'skip', oldCount: prev.count } : { action: 'replace', oldCount: prev.count };
}

export const passageIds = (docId, count) => Array.from({ length: count }, (_, i) => `${docId}#${i}`);

export const staleDocIds = (manifestKeys, seen, sources) =>
  manifestKeys.filter((k) => sources.includes(k.split(':')[0]) && !seen.has(k));
```

```js
#!/usr/bin/env node
// Incremental ingest of the SC Ask corpus into Upstash Vector (namespace "docs").
//   node --env-file=.env tools/commlink-corpus/ask/ingest.mjs --sources comm,dev,ledger
//   ... --dry-run            count docs/passages, write nothing
//   ... --limit 20           cap new/changed docs (smoke test; disables stale deletion)
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { loadAllDocs } from './sources.mjs';
import { docToPassages } from './passages.mjs';
import { contentHash, manifestValue, planDoc, passageIds, staleDocIds } from './manifest.mjs';
import { docsNs, redis } from './upstash.mjs';

const HERE = path.dirname(fileURLToPath(import.meta.url));
const DATA_DIR = path.join(HERE, '..', 'data');
const CLAIMS_DIR = process.env.ASK_CLAIMS_DIR || path.join(HERE, '..', '..', '..', 'docs', 'claims');
const BATCH = 100;

const arg = (name) => { const i = process.argv.indexOf(`--${name}`); return i > -1 ? process.argv[i + 1] : undefined; };
const DRY = process.argv.includes('--dry-run');
const LIMIT = arg('limit') ? Number(arg('limit')) : Infinity;
const SOURCES = (arg('sources') || 'comm,dev,yt,ledger').split(',');

const startedMs = Date.now();
const r = DRY ? null : redis();
const docs = DRY ? null : docsNs();
const manifest = DRY ? {} : ((await r.hgetall('ingest:manifest')) ?? {});

const stats = { insert: 0, replace: 0, skip: 0, passages: 0, deleted: 0 };
const seen = new Set();
let newest = '';
let batch = [];
let pending = {};

async function flush() {
  if (!batch.length) return;
  await docs.upsert(batch);
  await r.hset('ingest:manifest', pending);
  batch = [];
  pending = {};
}

for await (const doc of loadAllDocs({ dataDir: DATA_DIR, claimsDir: CLAIMS_DIR, sources: SOURCES })) {
  seen.add(doc.docId);
  if (doc.sourceType !== 'ledger' && doc.date > newest) newest = doc.date;
  const hash = contentHash(doc);
  const plan = planDoc(hash, manifest[doc.docId]);
  if (plan.action === 'skip') { stats.skip++; continue; }
  if (stats.insert + stats.replace >= LIMIT) continue;
  const passages = docToPassages(doc, startedMs);
  stats[plan.action]++;
  stats.passages += passages.length;
  if (DRY) continue;
  if (plan.action === 'replace') await docs.delete(passageIds(doc.docId, plan.oldCount));
  batch.push(...passages);
  pending[doc.docId] = manifestValue(hash, passages.length);
  if (batch.length >= BATCH) await flush();
}
if (!DRY) await flush();

if (!DRY && LIMIT === Infinity) {
  for (const id of staleDocIds(Object.keys(manifest), seen, SOURCES)) {
    await docs.delete(passageIds(id, Number(String(manifest[id]).split(':')[1]) || 0));
    await r.hdel('ingest:manifest', id);
    stats.deleted++;
  }
}
if (!DRY && newest) {
  const current = (await r.get('corpus:currentTo')) ?? '';
  if (newest > String(current)) await r.set('corpus:currentTo', newest);
}
if (!DRY) fs.writeFileSync(path.join(DATA_DIR, 'ask-last-ingest.json'), JSON.stringify({ startedMs, passages: stats.passages, docs: stats.insert + stats.replace }));
console.log(JSON.stringify({ sources: SOURCES, dryRun: DRY, ...stats, newest }));
```

```ts
// src/lib/retrieve.ts
import { QueryMode } from '@upstash/vector';
import { config } from './config';
import { docsNs } from './clients';
import type { Passage, PassageMeta, SourceCard } from './types';

export type Hit = { id: string | number; score: number; data?: string; metadata?: PassageMeta };
type Opts = { ledgerMinScore: number; maxPerDoc: number; keep: number; maxChars: number };

const valid = (h: Hit): h is Hit & { data: string; metadata: PassageMeta } => !!h.metadata && typeof h.data === 'string';

export function selectPassages(ledger: Hit[], main: Hit[], o: Opts): Passage[] {
  const led = ledger.filter(valid).filter((h) => h.score >= o.ledgerMinScore).slice(0, 3);
  const perDoc = new Map<string, number>();
  const picked: (Hit & { data: string; metadata: PassageMeta })[] = [];
  for (const h of main.filter(valid)) {
    if (led.length + picked.length >= o.keep) break;
    const c = perDoc.get(h.metadata.docId) ?? 0;
    if (c >= o.maxPerDoc) continue;
    perDoc.set(h.metadata.docId, c + 1);
    picked.push(h);
  }
  let chars = led.reduce((a, h) => a + h.data.length, 0);
  const kept = picked.filter((h) => (chars + h.data.length <= o.maxChars ? ((chars += h.data.length), true) : false));
  kept.sort((a, b) => a.metadata.date.localeCompare(b.metadata.date));
  return [...led, ...kept].map((h, i) => ({ n: i + 1, id: String(h.id), text: h.data, meta: h.metadata }));
}

export async function retrieve(question: string): Promise<Passage[]> {
  const ns = docsNs();
  const [ledger, main] = await Promise.all([
    ns.query<PassageMeta>({ data: question, topK: config.ledgerTopK, queryMode: QueryMode.DENSE, includeMetadata: true, includeData: true, filter: "sourceType = 'ledger'" }),
    ns.query<PassageMeta>({ data: question, topK: config.mainTopK, queryMode: QueryMode.HYBRID, includeMetadata: true, includeData: true, filter: "sourceType != 'ledger'" }),
  ]);
  return selectPassages(ledger as Hit[], main as Hit[], {
    ledgerMinScore: config.ledgerMatchScore, maxPerDoc: config.maxPerDoc, keep: config.keepPassages, maxChars: config.maxPassageChars,
  });
}

export const toCard = (p: Passage): SourceCard => ({
  n: p.n, sourceType: p.meta.sourceType, title: p.meta.title, date: p.meta.date, url: p.meta.url,
  author: p.meta.author, status: p.meta.status, excerpt: p.meta.excerpt,
});
```

```ts
// src/lib/parse.ts
// Streaming helpers: split the model's VERDICT/TOPIC/QUESTION header from the
// answer body, and validate [n] citations without breaking ones split across chunks.
import { TOPICS, VERDICTS } from './config';
import type { Header, Topic, Verdict } from './types';

const SEP = /\r?\n-{3,}[ \t]*\r?\n/;
const MAX_HEADER_WAIT = 600;

export function parseHeaderBlock(block: string, fallbackQuestion: string): Header {
  const get = (k: string) => block.match(new RegExp(`^[ \\t]*${k}:[ \\t]*(.*)$`, 'mi'))?.[1]?.trim() ?? '';
  const v = get('VERDICT').toLowerCase();
  const t = get('TOPIC');
  const q = get('QUESTION');
  return {
    verdict: (VERDICTS as readonly string[]).includes(v) ? (v as Verdict) : 'none',
    topic: (TOPICS as readonly string[]).find((x) => x.toLowerCase() === t.toLowerCase()) as Topic ?? 'Other',
    question: q || fallbackQuestion,
    parsed: true,
  };
}

export class HeaderParser {
  private buf = '';
  private done = false;
  constructor(private fallbackQuestion: string) {}

  private fallback(): Header {
    return { verdict: 'none', topic: 'Other', question: this.fallbackQuestion, parsed: false };
  }

  push(chunk: string): { header: Header | null; body: string } {
    if (this.done) return { header: null, body: chunk };
    this.buf += chunk;
    const m = this.buf.match(SEP);
    if (m && m.index !== undefined) {
      this.done = true;
      const header = parseHeaderBlock(this.buf.slice(0, m.index), this.fallbackQuestion);
      return { header, body: this.buf.slice(m.index + m[0].length) };
    }
    if (this.buf.length > MAX_HEADER_WAIT) {
      this.done = true;
      return { header: this.fallback(), body: this.buf };
    }
    return { header: null, body: '' };
  }

  end(): { header: Header | null; body: string } {
    if (this.done) return { header: null, body: '' };
    this.done = true;
    return { header: this.fallback(), body: this.buf };
  }
}

const CITE = /\[(\d+(?:\s*,\s*\d+)*)\]/g;

export class CitationFilter {
  private hold = '';
  private seen = new Set<number>();
  constructor(private maxN: number) {}

  private clean(text: string): string {
    return text.replace(CITE, (_, list: string) => {
      const ok = list.split(',').map((s) => Number(s.trim())).filter((n) => n >= 1 && n <= this.maxN);
      ok.forEach((n) => this.seen.add(n));
      return ok.length ? `[${ok.join(', ')}]` : '';
    });
  }

  push(text: string): string {
    const s = this.hold + text;
    const open = s.lastIndexOf('[');
    // hold back a possibly-incomplete citation like "[1" or "[2, 1"
    if (open > -1 && s.indexOf(']', open) === -1 && /^\[[\d,\s]*$/.test(s.slice(open)) && s.length - open <= 12) {
      this.hold = s.slice(open);
      return this.clean(s.slice(0, open));
    }
    this.hold = '';
    return this.clean(s);
  }

  flush(): string {
    const s = this.hold;
    this.hold = '';
    return this.clean(s);
  }

  cited(): number[] {
    return [...this.seen].sort((a, b) => a - b);
  }
}
```

```ts
export class FakeRedis {
  store = new Map<string, any>();
  ttl = new Map<string, number>();
  async get(k: string) { return this.store.get(k) ?? null; }
  async set(k: string, v: any, opts?: { ex?: number; nx?: boolean }) {
    if (opts?.nx && this.store.has(k)) return null;
    this.store.set(k, v); if (opts?.ex) this.ttl.set(k, opts.ex); return 'OK';
  }
  async del(...ks: string[]) { let n = 0; for (const k of ks) n += this.store.delete(k) ? 1 : 0; return n; }
  async incrby(k: string, n: number) { const v = Number(this.store.get(k) ?? 0) + n; this.store.set(k, v); return v; }
  async incr(k: string) { return this.incrby(k, 1); }
  async expire(k: string, s: number) { this.ttl.set(k, s); return 1; }
  async hincrby(k: string, f: string, n: number) { const h = this.store.get(k) ?? {}; h[f] = Number(h[f] ?? 0) + n; this.store.set(k, h); return h[f]; }
  async hset(k: string, obj: Record<string, any>) { this.store.set(k, { ...(this.store.get(k) ?? {}), ...obj }); return Object.keys(obj).length; }
```

```ts
// Haiku 4.5: $1/MTok in, $5/MTok out → 1 and 5 microdollars per token.
import { config } from './config';
import { redis } from './clients';

type R = Pick<ReturnType<typeof redis>, 'get' | 'set' | 'incrby' | 'expire'>;
export const dayKey = (d: Date) => d.toISOString().slice(0, 10);
export const monthKey = (d: Date) => d.toISOString().slice(0, 7);
export const costMicros = (u: { input_tokens: number; output_tokens: number }) => u.input_tokens * 1 + u.output_tokens * 5;

export async function addSpend(micros: number, r: R = redis(), now = new Date()) {
  const month = monthKey(now);
  const monthMicros = Number(await r.incrby(`spend:${month}`, micros));
  const dk = `spend:day:${dayKey(now)}`;
  await r.incrby(dk, micros);
  await r.expire(dk, 40 * 24 * 3600);
  let crossedWarn = false;
  if (monthMicros >= config.monthlyCapMicros * 0.8) {
    crossedWarn = (await r.set(`spend:warned:${month}`, '1', { nx: true, ex: 40 * 24 * 3600 })) === 'OK';
  }
  return { monthMicros, crossedWarn };
}

export async function capState(r: R = redis(), now = new Date()): Promise<'ok' | 'over'> {
  const spent = Number((await r.get(`spend:${monthKey(now)}`)) ?? 0);
  return spent >= config.monthlyCapMicros ? 'over' : 'ok';
}
```

```ts
import { redis } from './clients';
import { dayKey } from './spend';

type R = Pick<ReturnType<typeof redis>, 'hincrby' | 'expire' | 'hset' | 'hgetall' | 'incr'>;
const DAY_TTL = 400 * 24 * 3600;
const WINDOW_DAYS = { week: 7, month: 30 } as const;

export async function recordAsk(qid: string, question: string, topic: string, r: R = redis(), now = new Date()) {
  const k = `asked:${dayKey(now)}`;
  await Promise.all([r.hincrby(k, qid, 1), r.hincrby('asked:all', qid, 1), r.hset(`q:${qid}`, { question, topic })]);
  await r.expire(k, DAY_TTL);
}

export async function recordHitMiss(hit: boolean, r: R = redis(), now = new Date()) {
  const k = `${hit ? 'hits' : 'misses'}:${dayKey(now)}`;
  await r.incr(k);
  await r.expire(k, DAY_TTL);
}

export async function popular(window: 'week' | 'month' | 'all', topic: string | null, r: R = redis(), now = new Date()) {
  const counts: Record<string, number> = {};
  const add = (h: Record<string, unknown> | null) => { for (const [q, c] of Object.entries(h ?? {})) counts[q] = (counts[q] ?? 0) + Number(c); };
  if (window === 'all') add(await r.hgetall('asked:all'));
  else {
    const days = Array.from({ length: WINDOW_DAYS[window] }, (_, i) => dayKey(new Date(now.getTime() - i * 86_400_000)));
    (await Promise.all(days.map((d) => r.hgetall(`asked:${d}`)))).forEach((h) => add(h as Record<string, unknown> | null));
  }
  const qids = Object.keys(counts);
  const labels = await Promise.all(qids.map((q) => r.hgetall(`q:${q}`)));
  return qids
    .map((qid, i) => ({ qid, question: String((labels[i] as any)?.question ?? ''), topic: String((labels[i] as any)?.topic ?? 'Other'), count: counts[qid] }))
    .filter((x) => x.question && (!topic || x.topic === topic))
    .sort((a, b) => b.count - a.count || a.question.localeCompare(b.question))
    .slice(0, 15);
}
```

```ts
// src/lib/cache.ts
import { QueryMode } from '@upstash/vector';
import { config } from './config';
import { cacheNs, redis } from './clients';
import type { CacheRecord } from './types';

type Ns = { query: (q: any) => Promise<any[]>; upsert: (v: any) => Promise<unknown>; delete: (ids: any) => Promise<unknown> };
type R = Pick<ReturnType<typeof redis>, 'get' | 'set' | 'del'>;
type Deps = { r?: R; ns?: Ns };
const d = (deps: Deps = {}) => ({ r: deps.r ?? redis(), ns: deps.ns ?? (cacheNs() as unknown as Ns) });

export async function getCached(qid: string, deps?: Deps) {
  return ((await d(deps).r.get(`cache:${qid}`)) as CacheRecord | null) ?? null;
}

export async function lookupCache(question: string, deps?: Deps): Promise<CacheRecord | null> {
  const { r, ns } = d(deps);
  const [top] = await ns.query({ data: question, topK: 1, queryMode: QueryMode.DENSE });
  if (!top || top.score < config.cacheHitScore) return null;
  const rec = (await r.get(`cache:${top.id}`)) as CacheRecord | null;
  if (!rec) { await ns.delete([String(top.id)]); return null; }
  return rec;
}

export async function writeCache(rec: CacheRecord, deps?: Deps) {
  const { r, ns } = d(deps);
  await r.set(`cache:${rec.qid}`, rec, { ex: config.cacheTtlSeconds });
  await ns.upsert({ id: rec.qid, data: rec.question, metadata: { qid: rec.qid } });
}

export async function evict(qid: string, deps?: Deps) {
  const { r, ns } = d(deps);
  await r.del(`cache:${qid}`);
  await ns.delete([qid]);
}
```

```ts
// src/lib/ndjson.ts
import type { AskEvent } from './types';

export function toNdjsonStream(events: AsyncIterable<AskEvent>): ReadableStream<Uint8Array> {
  const enc = new TextEncoder();
  return new ReadableStream({
    async start(controller) {
      for await (const e of events) controller.enqueue(enc.encode(JSON.stringify(e) + '\n'));
      controller.close();
    },
  });
}

export async function* readNdjson<T>(res: Response): AsyncGenerator<T> {
  const reader = res.body!.getReader();
  const dec = new TextDecoder();
  let buf = '';
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    buf += dec.decode(value, { stream: true });
    let i;
    while ((i = buf.indexOf('\n')) > -1) {
      const line = buf.slice(0, i).trim();
      buf = buf.slice(i + 1);
      if (line) yield JSON.parse(line) as T;
    }
  }
  if (buf.trim()) yield JSON.parse(buf) as T;
}
```

```ts
export function generate(system: string, user: string) {
  const stream = anthropic().messages.stream({
    model: MODEL,
    max_tokens: config.maxOutputTokens,
    system,
    messages: [{ role: 'user', content: user }],
  });
  const usage = stream.finalMessage().then((m) => ({ input_tokens: m.usage.input_tokens, output_tokens: m.usage.output_tokens }));
  usage.catch(() => {});
  async function* text() {
    for await (const ev of stream) {
      if (ev.type === 'content_block_delta' && ev.delta.type === 'text_delta') yield ev.delta.text;
    }
  }
  return { stream: text(), usage };
}
```

```ts
// Orchestration for one question. Dependency-injected so it's testable without network.
import { config } from './config';
import { qidFor } from './qid';
import { SYSTEM_PROMPT, buildUserMessage } from './prompt';
import { HeaderParser, CitationFilter } from './parse';
import { costMicros } from './spend';
import { answerCard } from './asklog';
import { toCard } from './retrieve';
import type { AskEvent, CacheRecord, Header, Passage } from './types';

export interface AskDeps {
  enabled: () => boolean;
  capState: () => Promise<'ok' | 'over'>;
  lookupCache: (q: string) => Promise<CacheRecord | null>;
  getCached: (qid: string) => Promise<CacheRecord | null>;
  checkRate: (ip: string) => Promise<boolean>;
  retrieve: (q: string) => Promise<Passage[]>;
  generate: (system: string, user: string) => { stream: AsyncIterable<string>; usage: Promise<{ input_tokens: number; output_tokens: number }> };
  writeCache: (rec: CacheRecord) => Promise<void>;
  recordAsk: (qid: string, question: string, topic: string) => Promise<void>;
  recordHitMiss: (hit: boolean) => Promise<void>;
  addSpend: (micros: number) => Promise<{ monthMicros: number; crossedWarn: boolean }>;
  currentTo: () => Promise<string>;
  postAskLog: (p: { content?: string; embeds?: object[] }) => Promise<void>;
}

const err = (code: Extract<AskEvent, { type: 'error' }>['code'], message: string): AskEvent => ({ type: 'error', code, message });

async function* replay(rec: CacheRecord, d: AskDeps, count: boolean): AsyncGenerator<AskEvent> {
  yield { type: 'sources', sources: rec.sources, currentTo: rec.currentTo };
  yield { type: 'header', verdict: rec.verdict, topic: rec.topic, question: rec.question };
  yield { type: 'delta', text: rec.answer };
  yield { type: 'done', qid: rec.qid, cached: true, cited: rec.cited };
  if (count) await Promise.all([d.recordAsk(rec.qid, rec.question, rec.topic), d.recordHitMiss(true)]).catch(() => {});
}

export async function* handleAsk(input: { question?: string; qid?: string; ip: string }, d: AskDeps, opts: { eval?: boolean } = {}): AsyncGenerator<AskEvent> {
  if (!d.enabled()) return yield err('disabled', 'SC Ask is temporarily offline.');

  if (input.qid && !opts.eval) {
    const rec = await d.getCached(input.qid).catch(() => null);
    if (rec) return yield* replay(rec, d, true);
    if (!input.question) return yield err('input', 'That answer has expired — ask the question again.');
  }

  const question = (input.question ?? '').trim();
  if (!question || question.length > config.maxQuestionChars) return yield err('input', `Questions must be 1–${config.maxQuestionChars} characters.`);

  if (!opts.eval) {
    const hit = await d.lookupCache(question).catch(() => null);
    if (hit) return yield* replay(hit, d, true);
  }

  // Redis trouble fails open here; the Anthropic workspace limit is the hard backstop.
  if ((await d.capState().catch(() => 'ok' as const)) === 'over') return yield err('cap', 'Monthly question limit reached — cached answers still work.');
  if (!opts.eval && !(await d.checkRate(input.ip).catch(() => true))) return yield err('rate', "You're asking a lot — try again in a bit.");

  let passages: Passage[];
  try { passages = await d.retrieve(question); } catch { return yield err('search', 'Search is unavailable right now — try again shortly.'); }
  const sources = passages.map(toCard);
  const currentTo = await d.currentTo().catch(() => '');
  yield { type: 'sources', sources, currentTo };

  const hp = new HeaderParser(question);
  const cf = new CitationFilter(passages.length);
  let header: Header | null = null;
  let answer = '';
  const gen = d.generate(SYSTEM_PROMPT, buildUserMessage(question, passages));
  gen.usage.catch(() => {}); // avoid an unhandled rejection if the stream fails first
  const emit = (r: { header: Header | null; body: string }): AskEvent[] => {
    const out: AskEvent[] = [];
    if (r.header) { header = r.header; out.push({ type: 'header', verdict: r.header.verdict, topic: r.header.topic, question: r.header.question }); }
    const safe = r.body ? cf.push(r.body) : '';
    if (safe) { answer += safe; out.push({ type: 'delta', text: safe }); }
    return out;
  };
  try {
    for await (const chunk of gen.stream) for (const e of emit(hp.push(chunk))) yield e;
    for (const e of emit(hp.end())) yield e;
    const tail = cf.flush();
    if (tail) { answer += tail; yield { type: 'delta', text: tail }; }
  } catch {
    return yield err('model', 'The answer engine hit an error — please try again.');
  }

  const usage = await gen.usage.catch(() => ({ input_tokens: 0, output_tokens: 0 }));
  const micros = costMicros(usage);
  const h = header as Header | null;
  const cacheable = !!h && h.parsed && answer.trim().length > 0;
  const qid = cacheable ? await qidFor(h!.question) : null;
  yield { type: 'done', qid, cached: false, cited: cf.cited() };

  const spend = await d.addSpend(micros).catch(() => ({ monthMicros: 0, crossedWarn: false }));
  if (opts.eval) return;
  await d.recordHitMiss(false).catch(() => {});
  if (spend.crossedWarn) await d.postAskLog({ content: `⚠️ SC Ask has used 80% of this month's cap ($${(spend.monthMicros / 1e6).toFixed(2)}).` });
  if (!cacheable || !qid || !h) {
    await d.postAskLog({ content: `⚠️ Unparsed answer header for: ${question.slice(0, 200)}` });
    return;
  }
  const rec: CacheRecord = { qid, question: h.question, verdict: h.verdict, topic: h.topic, answer, sources, cited: cf.cited(), createdAt: new Date().toISOString(), currentTo };
  await Promise.all([d.writeCache(rec), d.recordAsk(qid, h.question, h.topic)]).catch(() => {});
  await d.postAskLog({ embeds: [answerCard(rec, micros)] });
}
```

```tsx
const ICON = { comm: '📰 Comm-link', dev: '💬 Dev post', yt: '▶ Video', ledger: '🛡 Day One Citizen fact-check' } as const;

function withAnchors(text: string, id: string) {
  const parts = text.split(/(\[\d+(?:,\s*\d+)*\])/g);
  return parts.map((p, i) => {
    const m = p.match(/^\[(\d+(?:,\s*\d+)*)\]$/);
    if (!m) return <span key={i}>{p}</span>;
    return <sup key={i}>{m[1].split(',').map((n) => n.trim()).map((n) => <a key={n} href={`#${id}-src-${n}`}>[{n}]</a>)}</sup>;
  });
}

export function AnswerCard({ a }: { a: AnswerState }) {
  const [voted, setVoted] = useState<'up' | 'down' | null>(null);
  const cited = a.sources.filter((s) => a.cited.includes(s.n));
  const vote = async (v: 'up' | 'down') => {
    if (!a.qid || voted) return;
    setVoted(v);
    await fetch('/api/feedback', { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify({ qid: a.qid, vote: v }) });
  };
  return (
    <article className="card">
```

```tsx
// src/components/Chat.tsx
'use client';
import { useState } from 'react';
import { readNdjson } from '@/lib/ndjson';
import type { AskEvent } from '@/lib/types';
import { AnswerCard, type AnswerState } from './AnswerCard';
import { MostAsked } from './MostAsked';

const EXAMPLES = ['Did CIG say ships won’t be wiped anymore?', 'Is the Hull-C in the game?', 'Can I build my own base yet?', 'Does Star Citizen support VR?'];

export function Chat() {
  const [input, setInput] = useState('');
  const [answers, setAnswers] = useState<AnswerState[]>([]);
  const [busy, setBusy] = useState(false);
  const [refresh, setRefresh] = useState(0);

  async function ask(body: { question?: string; qid?: string }, label: string) {
    if (busy) return;
    setBusy(true);
    const id = `a${Date.now()}`;
    const blank: AnswerState = { id, asked: label, text: '', sources: [], cited: [], qid: null, cached: false, currentTo: '', done: false };
    setAnswers((prev) => [blank, ...prev]);
    const patch = (p: Partial<AnswerState> | ((a: AnswerState) => Partial<AnswerState>)) =>
      setAnswers((prev) => prev.map((a) => (a.id === id ? { ...a, ...(typeof p === 'function' ? p(a) : p) } : a)));
    try {
      const res = await fetch('/api/ask', { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify(body) });
      if (res.status === 401) { window.location.href = '/login'; return; }
      for await (const e of readNdjson<AskEvent>(res)) {
        if (e.type === 'sources') patch({ sources: e.sources, currentTo: e.currentTo });
        else if (e.type === 'header') patch({ verdict: e.verdict, topic: e.topic, question: e.question });
        else if (e.type === 'delta') patch((a) => ({ text: a.text + e.text }));
        else if (e.type === 'done') patch({ done: true, qid: e.qid, cached: e.cached, cited: e.cited });
        else if (e.type === 'error') patch({ done: true, error: e.message });
      }
      patch((a) => (a.done ? {} : { done: true, error: 'The answer was cut off — please try again.' }));
    } catch {
      patch({ done: true, error: 'Network error — please try again.' });
    } finally {
      setBusy(false);
      setRefresh((n) => n + 1);
    }
  }

  const submit = () => { const q = input.trim(); if (q) { setInput(''); ask({ question: q }, q); } };

  return (
    <div className="shell">
      <section>
        <h1 style={{ margin: '0 0 8px' }}>Ask about Star Citizen</h1>
        <form className="ask-form" onSubmit={(e) => { e.preventDefault(); submit(); }}>
          <textarea value={input} maxLength={500} placeholder="Ask anything — or paste something you heard." onChange={(e) => setInput(e.target.value)}
            onKeyDown={(e) => { if (e.key === 'Enter' && !e.shiftKey) { e.preventDefault(); submit(); } }} />
          <button type="submit" disabled={busy || !input.trim()}>Ask</button>
        </form>
        <div className="chips">{EXAMPLES.map((x) => <button key={x} className="chip" onClick={() => ask({ question: x }, x)}>{x}</button>)}</div>
        {answers.map((a) => <AnswerCard key={a.id} a={a} />)}
      </section>
      <MostAsked refreshKey={refresh} onPick={(i) => ask({ qid: i.qid, question: i.question }, i.question)} />
    </div>
  );
}
```

```js
#!/usr/bin/env node
// Evict cached answers that newly ingested passages would change.
// Dense-mode scores are used on both sides: hybrid (RRF) scores are rank-relative
// and not comparable across a filtered query, so a fixed dense threshold is used.
//   node --env-file=.env tools/commlink-corpus/ask/invalidate.mjs
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { QueryMode } from '@upstash/vector';
import { docsNs, cacheNs, redis } from './upstash.mjs';
import { postAskLog } from './notify.mjs';

export const shouldEvict = (score, threshold) => typeof score === 'number' && score >= threshold;

async function main() {
  const last = JSON.parse(fs.readFileSync(path.join(path.dirname(fileURLToPath(import.meta.url)), '..', 'data', 'ask-last-ingest.json'), 'utf8'));
  if (!last.passages) return console.log('No new passages — nothing to invalidate.');
  const threshold = Number(process.env.INVALIDATE_SCORE || 0.86);
  const r = redis();
  const docs = docsNs();
  const cache = cacheNs();
  const evicted = [];
  let cursor = '0';
  do {
    const [next, keys] = await r.scan(cursor, { match: 'cache:*', count: 200 });
    cursor = String(next);
    for (const key of keys) {
      const rec = await r.get(key);
      if (!rec?.question) continue;
      const [top] = await docs.query({ data: rec.question, topK: 1, queryMode: QueryMode.DENSE, filter: `ingestedAtMs >= ${last.startedMs}` });
      if (shouldEvict(top?.score, threshold)) {
        await r.del(key);
        await cache.delete([rec.qid]);
        evicted.push(rec.question);
      }
    }
  } while (cursor !== '0');
  console.log(JSON.stringify({ evicted: evicted.length }));
  if (evicted.length) await postAskLog(`♻️ New sources changed ${evicted.length} cached answer(s): ${evicted.slice(0, 10).join(' · ')}`);
}

if (process.argv[1]?.endsWith('invalidate.mjs')) await main();
```

```js
#!/usr/bin/env node
// Daily #ask-log line: yesterday's questions, cache hit rate, spend, new passages.
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { redis } from './upstash.mjs';
import { postAskLog } from './notify.mjs';

export const yesterdayUtc = (now) => new Date(now.getTime() - 86_400_000).toISOString().slice(0, 10);

export function formatSummary(s) {
  const pct = s.hits + s.misses ? Math.round((100 * s.hits) / (s.hits + s.misses)) : 0;
  const usd = (m) => `$${(m / 1e6).toFixed(2)}`;
  return `📊 SC Ask ${s.day} — ${s.asked} questions · ${s.hits} from cache (${pct}%) · ${usd(s.dayMicros)} spent · ${usd(s.monthMicros)} of $${s.capUsd} this month · +${s.newPassages} new passages · sources current to ${s.currentTo}`;
}

async function main() {
  const r = redis();
  const now = new Date();
  const day = yesterdayUtc(now);
  const asked = Object.values((await r.hgetall(`asked:${day}`)) ?? {}).reduce((a, n) => a + Number(n), 0);
  let newPassages = 0;
  try { newPassages = JSON.parse(fs.readFileSync(path.join(path.dirname(fileURLToPath(import.meta.url)), '..', 'data', 'ask-last-ingest.json'), 'utf8')).passages; } catch {}
  const line = formatSummary({
    day, asked,
    hits: Number((await r.get(`hits:${day}`)) ?? 0),
    misses: Number((await r.get(`misses:${day}`)) ?? 0),
    dayMicros: Number((await r.get(`spend:day:${day}`)) ?? 0),
    monthMicros: Number((await r.get(`spend:${now.toISOString().slice(0, 7)}`)) ?? 0),
    capUsd: Number(process.env.ASK_MONTHLY_CAP_USD || 10),
    newPassages,
    currentTo: String((await r.get('corpus:currentTo')) ?? 'unknown'),
  });
  console.log(line);
  await postAskLog(line);
}

if (process.argv[1]?.endsWith('summary.mjs')) await main();
```

```js
// eval/run.mjs — node --env-file=.env.local eval/run.mjs [BASE_URL]
import fs from 'node:fs';
import crypto from 'node:crypto';

const BASE = process.argv[2] || 'http://localhost:3000';
const cases = JSON.parse(fs.readFileSync(new URL('./cases.json', import.meta.url), 'utf8'));
const cookie = `ask_auth=${crypto.createHash('sha256').update(`${process.env.ASK_PASSWORD}:${process.env.ASK_COOKIE_SECRET}`).digest('hex')}`;

async function ask(q) {
  const res = await fetch(`${BASE}/api/ask`, { method: 'POST', headers: { 'content-type': 'application/json', cookie, 'x-eval-key': process.env.EVAL_KEY }, body: JSON.stringify({ question: q }) });
  const out = { sources: [], verdict: null, text: '', cited: [], error: null };
  for (const line of (await res.text()).split('\n').filter(Boolean)) {
    const e = JSON.parse(line);
    if (e.type === 'sources') out.sources = e.sources;
    if (e.type === 'header') out.verdict = e.verdict;
    if (e.type === 'delta') out.text += e.text;
    if (e.type === 'done') out.cited = e.cited;
    if (e.type === 'error') out.error = e.message;
  }
  return out;
}

let correct = 0, invented = 0, uncited = 0, sentences = 0;
const rows = [];
for (const c of cases) {
  const r = await ask(c.q);
  const ok = !r.error && c.expect.includes(r.verdict)
    && (!c.mustContain || r.text.includes(c.mustContain))
    && (!c.mustNotContain || !r.text.includes(c.mustNotContain));
  if (ok) correct++;
  const nums = [...r.text.matchAll(/\[(\d+)/g)].map((m) => Number(m[1]));
  invented += nums.filter((n) => n < 1 || n > r.sources.length).length;
  if (r.verdict !== 'none') {
    const ss = r.text.split(/(?<=[.!?])\s+/).filter((s) => s.trim().length > 20);
    sentences += ss.length;
    uncited += ss.filter((s) => !/\[\d/.test(s) && !/couldn't find/i.test(s)).length;
  }
  rows.push(`${ok ? '✅' : '❌'} ${c.id.padEnd(12)} got=${String(r.verdict).padEnd(12)} want=${c.expect.join('|')}${r.error ? ` ERR ${r.error}` : ''}`);
}
console.log(rows.join('\n'));
const acc = correct / cases.length;
console.log(`\nverdict accuracy ${(acc * 100).toFixed(1)}% (${correct}/${cases.length}) · invented citations ${invented} · uncited sentences ${uncited}/${sentences}`);
process.exit(acc >= 0.9 && invented === 0 ? 0 : 1);
```

```js
// Prints dense scores for same-meaning vs different-meaning question pairs so the
// cache threshold sits between them.
import { Index, QueryMode } from '@upstash/vector';

const ns = new Index({ url: process.env.UPSTASH_VECTOR_REST_URL, token: process.env.UPSTASH_VECTOR_REST_TOKEN }).namespace('probe');
const same = [
  ['Will my ships be wiped?', 'do ships get wiped in the next patch'],
  ['Is insurance permanent?', 'does LTI last forever'],
  ['Can I build my own base?', 'is base building in the game yet'],
  ['Does Star Citizen support VR?', 'can I play star citizen with a vr headset'],
  ['Is the Hull-C in the game?', 'has the hull c been released'],
];
const diff = [
  ['Will my ships be wiped?', 'Will my aUEC be wiped?'],
  ['Is the Hull-C in the game?', 'Is the Hull-E in the game?'],
  ['Is insurance permanent?', 'How long do insurance claims take?'],
];
for (const [i, [a]] of [...same, ...diff].entries()) await ns.upsert({ id: `p${i}`, data: a });
await new Promise((r) => setTimeout(r, 3000));
const score = async (i, b) => (await ns.query({ data: b, topK: 10, queryMode: QueryMode.DENSE })).find((h) => h.id === `p${i}`)?.score ?? 0;
for (const [label, pairs, off] of [['SAME', same, 0], ['DIFF', diff, same.length]]) {
  for (const [j, [a, b]] of pairs.entries()) console.log(label, (await score(off + j, b)).toFixed(4), `${a} | ${b}`);
}
await new Index({ url: process.env.UPSTASH_VECTOR_REST_URL, token: process.env.UPSTASH_VECTOR_REST_TOKEN }).deleteNamespace('probe');
```
