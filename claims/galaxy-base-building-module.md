Exact lines (CIG Spectrum, JCrewe_CIG, "Update on Galaxy's Base-Building Capabilities", 2024-10-25): "while there's no base-building module currently in active development for the Galaxy, we're fully committed to enabling a large base-building drone module for it down the line. The Galaxy won't be the first ship for building large-scale structures when base building launches, but will come soon-after, and its potential for that role is very much intact." Same post: "My earlier comment about when things are 'speculative' was incorrect."

**Same-day reversal.** Earlier on 2024-10-25, in the "Galaxy clarification" thread, the same staff member wrote that there were no current plans for a Galaxy base-building module. The update thread above replaced that position the same day — cite the update, not the earlier reply.

Origin: the CitizenCon 2953 "Destination Adventure" base-building presentation (2023-10-26): "with the Galaxy you can build small to large structures" (auto-captions, approximate). The 2022 Galaxy concept page (comm-link 18836) lists Cargo, Med Bay and Refinery modules plus "Manufacturing and other modules coming at a later date" — no base-building module is named there.

No release window for the module in any official source (comm-links, CIG-staff Spectrum archive and official video transcripts searched 2026-10-29). Re-check when base building ships.
